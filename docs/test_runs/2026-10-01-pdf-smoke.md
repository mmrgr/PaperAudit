## 复盘

### 已验证

1. PDF 本身可抽取文本，适合做离线输入完整性检查。
2. 独立适配层可以复用 PaperRevamper 的 DOCX 解析、确定性检查和证据门禁。
3. 对不支持的 PDF 直接调用，CLI 现在返回非零状态，调用方不会把“跳过”误判为“审查通过”。

### 暴露的问题

1. PDF 是 Elsevier 双栏排版，文本抽取会混入页眉页脚并改变列顺序。
2. 表格、图形、公式、字体样式和页码定位没有进入投影 DOCX。
3. 论文采用作者-年份引用，当前引用检测器主要识别 `[n]` 编号制，因此本次不能评价引用覆盖度。
4. 参考文献没有可靠地被识别为 bibliography，缩写检测出现明显误报。
5. 因此“1 项确认”只能说明适配链路运行成功，不能作为 PDF 论文质量结论。

这部分意见没有自动写回 PDF；涉及数字、SI、模型假设的修改均保留为作者确认项。

## 后续优先级

1. 若要正式支持 PDF，新增带页码/字符区间的 PDF `DocumentIR` 适配器，并单独处理双栏、表格、图形和作者-年份引用。
2. 在适配器层加入参考文献区识别，避免把 DOI、期刊缩写当作正文术语。
3. 用人工标注的 PDF 小样本建立回归基准，再比较原生 PDF 适配器与 DOCX 投影的 precision / recall。
