工作流画布

拖动 Agent 模块调整布局；上游模块的输出会沿箭头流向下游模块。顺序号仍决定实际执行批次，同序模块并行。

点击模块配置名称、提示和 Agent 参数；拖动只调整布局。普通箭头表示依赖，紫色虚线表示有次数上限的循环回流。
